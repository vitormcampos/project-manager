# ProjectHub.Contracts

Biblioteca compartilhada de DTOs e enums serializáveis usados na API e no cliente Blazor. `ProjectHub.Web` referencia este projeto para construir chamadas HTTP com os mesmos tipos de request/response da API.

Este projeto não referencia Domain, Application, Data ou ASP.NET Core. Mantenha aqui apenas contratos de transporte públicos e independentes; interfaces de serviço, entidades de domínio e detalhes de persistência pertencem às respectivas camadas.
